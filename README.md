# SYNC_Breath

SYNC_Breathは、AviUtl2で人物画像の上半身に自然な呼吸の動きを加えるフィルタープラグインです。フィルター一覧では「呼吸」と表示されます。

## 動作環境

- Windows 64-bit
- AviUtl2
- 人物が写った画像オブジェクト

## インストール

配布ZIP内の`SYNC_Breath`フォルダーを、次の場所へ配置します。

```text
C:\ProgramData\aviutl2\Plugin\SYNC_Breath
```

配置後、次のファイルが存在することを確認してください。

```text
C:\ProgramData\aviutl2\Plugin\SYNC_Breath\SYNC_Breath.auf2
```

AviUtl2を起動中の場合は、一度終了してからインストールまたは更新してください。

## 基本的な使い方

1. 人物画像のオブジェクトへ「呼吸」フィルターを追加します。
2. フィルターの`設定`ボタンを押します。
3. 表示された画像上で、頭・首・左右肩・胸・腰のガイド点を人物に合わせます。
4. 右クリックメニューからガイド編集、表示移動、全体表示、初期配置、呼吸プレビューを選択できます。
5. 設定画面を閉じると、ガイド位置が現在のオブジェクトへ保存されます。
6. AviUtl2側で呼吸タイプ、周期、強度、位相を調整します。

## 設定画面の操作

- ホイール：25%刻みで拡大縮小（25～400%）
- 左ドラッグ：ガイド点を移動。点以外では表示を移動
- 中ドラッグ：表示を移動
- ダブルクリック：全体表示と中央配置へ戻す
- 右クリック：操作メニューを表示

ガイドは、腰を基準に胸部を主、腹部を補助、肩・首・頭を弱く追従させる変形範囲を決めます。左右の肩は中心軸を越えないよう制限されます。

## パラメーター

| 項目 | 内容 |
| --- | --- |
| 呼吸タイプ | 通常のゆったりした呼吸と、荒い呼吸の種類を選択します。 |
| 周期 | 呼吸が1周期する時間を調整します。 |
| 強度 | 呼吸による変形の大きさを調整します。 |
| 位相 | 呼吸周期の開始位置をずらします。 |

## 配布ZIPの作成（開発者向け）

Release構成をビルドした後、次を実行します。

```text
Setup\make_release_zip.bat
```

成功すると、`Setup\SYNC_Breath.zip`が作成されます。ZIPには次の構成だけが含まれます。

```text
SYNC_Breath/
  SYNC_Breath.auf2
  README.md
```

作成前に、Release版の`.auf2`が存在すること、有効なPEファイルであること、Debug用の`.dll`と`.rsm`が配備先に残っていないことを検査します。
